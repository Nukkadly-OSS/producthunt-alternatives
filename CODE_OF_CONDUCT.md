# Code of conduct

This list is a shared public dataset. Keep issues and pull requests about the listings, not about the people.

- No harassment, slurs, or threats.
- No flooding the tracker with the same URL.
- Disclose when you own a submitted site.
- Assume maintainers will edit copy and may reject a listing that does not fit.

If someone is abusive, use GitHub report tools or contact a repo admin. Maintainers can close threads and block accounts that ignore this.
